# 🧾 Inventory Management System

A simple inventory management system built in Python using pandas. This project is designed to help learn key Python concepts like DataFrames, file I/O, and modular programming — with future options to expand into SQL or GUI.

---

## 📦 Features

- Product Catalog management
- Inventory stock-in and stock-out operations
- Sales tracking
- Transaction history
- Daily/weekly report printing
- Data stored in JSON/CSV
- Easy extension to GUI or SQL backends
