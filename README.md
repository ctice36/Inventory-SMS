# 🧾 Inventory Management System

A simple inventory management system built in Python using pandas. This project is designed to help learn key Python concepts like DataFrames, file I/O, and modular programming, with future options to expand into GUI.

---

## 📦 Features

- Product Catalogue management
- Inventory stock-in  operations
- Sales tracking
- Daily/weekly report printing
- Data stored in JSON
- Easy extension to GUI or SQL backends
